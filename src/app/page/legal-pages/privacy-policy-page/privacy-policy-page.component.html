Gestion d'IndexedDB

Qu'est ce qu'IndexedDB ?

IndexedDB est un système de stockage local de données structurées sur votre navigateur. Cette technologie est similaire aux cookies à l'exception que sa persistance n'est pas soumise à une durée. Pour supprimer les données liées à IndexedDB, videz le cache de votre naviguateur.

Pour en savoir davantage sur les données de navigation et leur incidence sur votre expérience de navigation, vous pouvez consulter le site de la CNIL.

Données nécessaires au site pour fonctionner

Dans IndexedDB est stocké la table "trip" décrivant toutes les données des réservations faites par l'utilisateur :

• startingDate : la date de début de la réservation

• endingDate : la date de fin de la réservation

• nbAdults : le nombre d'invités adulte pour cette réservation

• nbChildren : le nombre d'invités enfants pour cette réservation

• nbInfants : le nombre d'invités nourrissons pour cette réservation

• nbPets : le nombre d'animaux de companie pour cette réservation

Dans IndexedDB est stocké la table "user" décrivant les utilisateurs simulés et l'utilisateur final :

• email

• password : le mot de passe

• lastname : le nom de famille

• firstname : le prénom

Ces données sont exemptées de la nécessité d'obtenir le consentement, comme indiqué dans la délibération de la CNIL n°2020-091, dans la mesure où elles sont strictement nécessaires au bon fonctionnement du site.
